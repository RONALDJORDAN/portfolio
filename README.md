## 📂 Arquitetura do Ecossistema Web

O projeto é composto por 7 interfaces integradas de forma bidirecional:

```
├── index.html                 # Página principal (Hero 3D, Skills Fill, Selected Works com Menu Fixo, Bento Footer)
├── curriculo.html             # Currículo Web corporativo (Foto à esquerda, dados à direita, impressão e PDF)
├── innovrpa.html              # Estudo de caso: INNOVRPA (Motor Híbrido Zero-Leak em Pure C + .NET 8 WPF)
├── innovstock.html            # Estudo de caso: INNOVSTOCK (Plataforma Cloud PWA com Scanner QR em Tempo Real)
├── lagoinha-smc.html          # Estudo de caso: LAGOINHA SMC (CRM Web Full-Stack em Next.js 14 + PostgreSQL)
├── innovcore-ti.html          # Estudo de caso: INNOVCORE TI (Governança e Telemetria WMI em C# .NET 8)
├── projetos-innov.html        # Estudo de caso: PROJETOS INNOV (Monorepo Turborepo + CI/CD + Design System)
├── assets/
│   ├── profile.jpg            # Foto de perfil profissional
│   ├── curriculo.pdf          # Documento oficial para download
│   ├── icons/                 # Ícones SVG e asteriscos decorativos
│   └── projects/              # Galerias e capturas de tela dos sistemas
├── css/
│   ├── fonts.css              # Definições de tipografia otimizadas
│   ├── style.css              # Estilos da página principal e Bento Grid
│   ├── project.css            # Estilos unificados dos estudos de caso
│   ├── curriculo.css          # Estilos e regras de impressão (@media print)
│   └── tailwind.css           # Utilitários de layout
└── js/
    ├── app.js                 # Engine de animações (GSAP, Lenis, WebGL Three.js e Cursor 60fps)
    ├── data.js                # Configuração centralizada de dados
    └── libs/                  # Bibliotecas locais (Three.js, GSAP, ScrollTrigger, Lenis)
```

## 🚀 Projetos em Destaque

### 1. [INNOVRPA](innovrpa.html) — Motor Híbrido Zero-Leak de RPA
- **Stack**: Pure C (ANSI C), C# .NET 8, WPF, MVVM, Vision7, OpenCV, Win32 P/Invoke.
- **Diferencial**: Ciclo ininterrupto de 72h+ com 0% de vazamento de memória e latência inferior a 0.5ms.

### 2. [INNOVSTOCK](innovstock.html) — Plataforma PWA Cloud de Inventário
- **Stack**: React 18, TypeScript, Firebase Realtime Database, Camera QR Scanner, PWA.
- **Diferencial**: Sincronização multi-dispositivo em menos de 100ms e termos jurídicos digitais automatizados.

### 3. [LAGOINHA SMC](lagoinha-smc.html) — Ecossistema Web de Gestão Comunitária & CRM
- **Stack**: Next.js 14 App Router, PostgreSQL, Prisma ORM, PDFKit, RBAC Auth.
- **Diferencial**: Gestão multi-departamental com segregação de permissões e relatórios financeiros automáticos.

### 4. [INNOVCORE TI](innovcore-ti.html) — Governança de TI & Telemetria de Hardware
- **Stack**: C# .NET 8, WMI Telemetry, Win32 API, SQL Server, Task Parallel Library.
- **Diferencial**: Auditoria em tempo real de ativos físicos de TI com alertas térmicos em menos de 50ms.

### 5. [PROJETOS INNOV](projetos-innov.html) — Monorepo & Engenharia Distribuída
- **Stack**: Turborepo, pnpm Workspaces, GitHub Actions CI/CD, Shared Design System, OpenAPI.
- **Diferencial**: 85% de taxa de acerto em cache de compilação remota e contratos de microsserviços tipados.
