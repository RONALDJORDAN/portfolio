01 // STACK TÉCNICA

O Que Foi Usado Para Construir o Sistema

Cada tecnologia foi selecionada estrategicamente para garantir o equilíbrio perfeito entre controle nativo de hardware e produtividade corporativa:

C

Pure C (ANSI C / C11)

Responsável pelo núcleo de execução crítica e gerenciamento direto de ponteiros brutos na memória RAM, eliminando qualquer pausa imprevisível causada pelo Garbage Collector.

C#

C# .NET 8 (Modern Runtime)

Runtime de orquestração de alto nível, multithreading concorrente via TPL (Task Parallel Library) e ponte de comunicação assíncrona entre o núcleo nativo e os serviços corporativos.

UI

WPF (Windows Presentation Foundation)

Interface desktop responsiva em XAML sob o padrão MVVM rigoroso, oferecendo telemetria em tempo real, consoles de debug e inspeção visual de agentes de automação.

CV

Vision7 & OpenCV

Pipeline proprietário de Visão Computacional para OCR, detecção de elementos gráficos na tela por matching de template com tolerância a variação de escala e renderização sub-pixel.

API

P/Invoke & Win32 Native API

Camada de interoperabilidade C#/C nativa para envio de inputs sintéticos de teclado e mouse sem overhead, bypassando camadas de atraso do sistema operacional.

OPT

Valgrind & Profiler de Memória

Ferramentas de inspeção cirúrgica de memória utilizadas durante o ciclo de desenvolvimento para validação de retenção zero de buffers e vazamentos de ponteiros.

03 // VISÃO GERAL & CASOS DE USO

O Que É a Ferramenta e Para o Que Ela É Usada

01

O Que É a Ferramenta

O INNOVRPA é um motor de automação robótica de processos de arquitetura híbrida de alto desempenho. Foi projetado especificamente para resolver uma fraqueza crônica das ferramentas tradicionais de RPA do mercado: o consumo descontrolado de memória e a latência de execução ao operar em ciclos contínuos de longa duração.

A engenharia do sistema divide a carga de trabalho em dois mundos especializados:

  • Mundo Nativo (Pure C): Gerencia ponteiros diretos de memória, estruturas binárias compactas e processamento de frames em escala de microsegundos sem interferência do GC.
  • Mundo Gerenciado (C# .NET 8 / WPF): Fornece a inteligência de negócios, agendamento de tarefas, telemetria analítica e interface do operador com gráficos em tempo real.
02

Para o Que Ela É Usada

O sistema atua em ambientes corporativos de missão crítica para automatizar fluxos de trabalho que dependem de sistemas legados fechados e interfaces sem API pública:

✓
Automação em Sistemas Desktop Legados:

Interação autônoma com ERPs (SAP, TOTVS, Protheus), mainframes e ferramentas bancárias que não disponibilizam APIs modernas.

✓
Localização Visual Tolerante a Variações:

Uso do Vision7 para encontrar botões, campos e tabelas dinâmicas mesmo quando a resolução ou fonte do sistema hospedeiro é alterada.

✓
Processamento 24/7 de Alta Frequência:

Execução ininterrupta de conciliações fiscais, extração em massa de relatórios e digitação de dados sem quedas de performance.
