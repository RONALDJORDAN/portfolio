Arquitetura web contemporânea priorizando estabilidade transacional, segurança de dados sensíveis e relatórios auditáveis:

NXT

Next.js 14 & React 18

App Router moderno combinando Server Components para renderização ultra-rápida no servidor e Client Components interativos para formulários e filtros.

TS

TypeScript

Tipagem estrita em todas as camadas de negócios, contratos de entidades (Membros, Lideranças, Transações Financeiras) e validação de payloads com Zod.

DB

PostgreSQL & Prisma ORM

Banco relacional robusto com integridade referencial estrita, migrações automatizadas e queries transacionais para prevenção de concorrência financeira.

SEC

JWT & RBAC Security

Autenticação stateless segura com tokens criptografados e controle de acesso granular por papel (Pastor Presidente, Tesoureiro, Líder de Ministério, Membro).

PDF

PDFKit / Motor de Relatórios

Renderização vetorial direta de balancetes contábeis, certificados de batismo e listas de presença formatadas para impressão padrão A4 institucional.

CSS

Tailwind CSS & Visual Tables

Design responsivo com tabelas de alta densidade de dados, paginação inteligente, ordenação dinâmica e visualização de status em badges temáticos.

03 // VISÃO GERAL & CASOS DE USO

O Que É a Ferramenta e Para o Que Ela É Usada

01

O Que É a Ferramenta

O LAGOINHA SMC é um ecossistema web corporativo desenvolvido para unificar toda a gestão comunitária, membros, voluntariado e saúde financeira da igreja. Antes de sua implantação, as informações ficavam fragmentadas entre cadernos físicos, planilhas esparsas e grupos de mensagens, inviabilizando uma visão executiva consolidada.

O sistema consolida a administração em uma plataforma centralizada de alta disponibilidade, acessível em tempo real pelos pastores, líderes departamentais e equipe de tesouraria de qualquer dispositivo com navegação segura.

02

Para o Que Ela É Usada

O sistema atua diretamente na rotina pastoral e administrativa da instituição:

✓
Gestão Integral do Ciclo de Membresia:

Registro de novos convertidos, agendamento de batismos, registro de células e emissão de cartões de membro digitais.

✓
Tesouraria e Prestação de Contas:

Conciliação de entradas e saídas divididas por ministérios específicos (Infantil, Jovens, Missões) com relatórios transparentes.

✓
Escalação & Orquestração de Eventos:

Controle de escalas de voluntários para cultos, conferências e eventos, evitando sobreposição e garantindo equipe completa.
