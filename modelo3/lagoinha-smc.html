// O Desafio Técnico

Fragmentação de planilhas e inconsistência nos registros financeiros

Diferentes ministérios utilizavam controles manuais descentralizados, gerando duplicidade em cadastros, demora na emissão de relatórios mensais e ausência de trilhas de auditoria para operações financeiras.

// A Solução de Engenharia

Arquitetura Serverless com Next.js & PostgreSQL

Desenvolvi uma aplicação full-stack com Next.js e Prisma ORM sobre PostgreSQL, implementando autenticação segura com JWT, controle de acesso baseado em papéis (RBAC) e dashboards com relatórios contábeis dinâmicos exportáveis em PDF e Excel.

// Stack Tecnológica

Next.js TypeScript PostgreSQL Prisma ORM Node.js Tailwind CSS Chart.js
