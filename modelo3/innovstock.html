// O Desafio Técnico

Desconexões em campo e morosidade na triagem de milhares de ativos

Equipes técnicas realizavam auditorias patrimoniais com planilhas desconectadas, resultando em dados conflitantes, lentidão no upload de imagens em redes 4G instáveis e emissão manual de termos jurídicos com risco de inconformidade LGPD.

// A Solução de Engenharia

PWA Offline-First com Sincronização Reativa

Estruturei um aplicativo progressivo (PWA) utilizando Web Workers e IndexedDB para cache local, conectado à árvore de dados do Firebase Realtime DB. Implementei compressão client-side via Canvas HTML5 para converter fotos de equipamentos para WebP antes do envio e um leitor óptico contínuo com debounce para agilizar a baixa de centenas de itens por minuto.

// Stack Tecnológica

React TypeScript Firebase RTDB PWA Service Workers Tailwind CSS Canvas WebP
