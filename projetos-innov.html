01 // STACK TÉCNICA

O Que Foi Usado Para Construir o Sistema

Ferramental de engenharia de ponta desenhado para máxima velocidade de compilação, modularidade e zero repetição de código:

TR

Turborepo & pnpm Workspaces

Orquestrador de monorepo de alto desempenho com grafo de dependências otimizado e cache remoto inteligente, reduzindo o tempo de build em 85%.

TS

TypeScript (Strict Monorepo Config)

Configuração centralizada com Project References, garantindo checagem incremental de tipos e propagação de interfaces entre pacotes sem re-compilar tudo.

UI

Shared Design System Package

Pacote interno de componentes React desacoplados com Tailwind CSS e tokens de design unificados, consumido por todas as aplicações do ecossistema.

ACT

GitHub Actions CI/CD

Esteira automatizada com execução condicional que roda testes e linters somente nos pacotes alterados pelo Pull Request via git diff.

DOC

Docker & Multi-Stage Builds

Imagens Docker ultra-enxutas geradas a partir do monorepo para cada microsserviço individual, otimizando o consumo de memória em produção.

VER

Changesets & Semantic Release

Governança automática de versões com Changelogs gerados a cada release e publicação de pacotes com versionamento semântico rigoroso (SemVer).

03 // VISÃO GERAL & CASOS DE USO

O Que É a Ferramenta e Para o Que Ela É Usada

01

O Que É a Ferramenta

O PROJETOS INNOV é a espinha dorsal da engenharia de software da InnovCore. Desenvolvido como um monorepo corporativo em Turborepo e pnpm, ele reúne todas as bibliotecas de interface, microsserviços, utilitários centrais e esteiras de automação sob um mesmo teto governado.

Em vez de manter dezenas de repositórios isolados com dependências desatualizadas e componentes duplicados, o Projetos Innov garante que uma correção em um componente de UI ou utilitário de autenticação seja propagada instantaneamente para todos os produtos do ecossistema com tipagem garantida.

02

Para o Que Ela É Usada

A estrutura atua como alicerce técnico e acelerador de desenvolvimento para os produtos da empresa:

✓
Desenvolvimento de Novos Produtos em Tempo Recorde:

Novos sistemas aproveitam imediatamente componentes visuais, autenticação e utilitários prontos do monorepo.

✓
Integração Contínua com Build Inteligente:

A esteira do Turborepo identifica dependências não alteradas e reutiliza artefatos em cache, economizando custos e tempo de CI.

✓
Conformidade e Qualidade Unificada:

Regras estritas de ESLint, TypeScript e testes automatizados aplicadas de maneira uniforme em 100% dos serviços.
