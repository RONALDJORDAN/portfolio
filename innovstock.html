01 // STACK TÉCNICA

O Que Foi Usado Para Construir o Sistema

Stack moderna orientada a mobilidade, conectividade contínua e tolerância a falhas em armazéns físicos:

RT

React 18 & TypeScript

Frontend tipado de ponta a ponta com renderização concorrente, hooks customizados para escuta de streams em tempo real e controle absoluto de estado.

DB

Firebase Realtime Database

Banco NoSQL com sincronização baseada em WebSockets de baixa latência (<100ms), propagando alterações de estoque para todos os operadores simultaneamente.

PWA

Progressive Web App (PWA)

Service Workers para cache agressivo de ativos e persistência offline com IndexedDB, permitindo operação mesmo em zonas de armazém sem sinal de internet.

CAM

HTML5 Barcode Detection API

Acesso nativo à câmera de dispositivos móveis com aceleração de hardware para decodificação instantânea de códigos EAN, UPC e QR Codes.

CSS

Tailwind CSS & Micro-interações

Design system responsivo focado em usabilidade com uma mão em ambiente de galpão, com botões amplos, contrastes fortes e feedback háptico.

DOC

Canvas Digital Signature & PDF

Coleta de assinaturas vetoriais na tela touch do dispositivo e compilação instantânea em documentos jurídicos de custódia com hash criptográfico.

Habilidades de Engenharia Aplicadas

Técnicas de engenharia de software empregadas para assegurar integridade de dados e alta performance móvel:

Arquitetura de dados orientada a eventos com delta updates em tempo real em menos de 100ms entre dispositivos distantes.

03 // VISÃO GERAL & CASOS DE USO

O Que É a Ferramenta e Para o Que Ela É Usada

01

O Que É a Ferramenta

O INNOVSTOCK é uma plataforma corporativa em nuvem desenvolvida como Progressive Web App (PWA) de controle de ativos patrimoniais e telemetria de estoques. Ele foi criado com o propósito de extinguir de vez o uso de planilhas de Excel compartilhadas e registros manuais em pranchetas, que frequentemente geram perdas financeiras, dados duplicados e descontrole de ativos entre filiais.

A ferramenta combina a versatilidade de um app móvel com a força de um sistema corporativo completo, permitindo que qualquer colaborador com um smartphone realize inventários completos utilizando a câmera do aparelho como leitor biométrico de códigos.

02

Para o Que Ela É Usada

O sistema é empregado diariamente em operações logísticas, setores de TI e controle de ativos corporativos:

✓
Conferência Ultrarrápida de Galpão:

Inventário físico em segundos apontando a câmera do celular para caixas, paletes e equipamentos individuais.

✓
Assinatura de Termos de Entrega:

Quando um funcionário recebe um notebook ou ferramenta, ele assina o termo de custódia diretamente na tela do smartphone.

✓
Gestão Multi-filial Centralizada:

Acompanhamento em tempo real pelo time executivo de onde cada item está alocado e seu histórico de transferências.
